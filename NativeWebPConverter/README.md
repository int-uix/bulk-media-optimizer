# Native WebP Converter (SwiftUI)

This is a fully native macOS SwiftUI app (Apple Silicon) that replaces the Tkinter UI.

## Build app

```bash
cd "NativeWebPConverter"
./scripts/build_native_app.sh
```

Output:

- `build/WebP Converter.app`

## Build DMG

```bash
./scripts/make_native_dmg.sh
```

Output:

- `build/WebP-Converter-Native-apple-silicon.dmg`
